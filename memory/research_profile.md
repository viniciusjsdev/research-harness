# Research Profile

This file describes the stable research identity of the project.

## Domains

- Domain-agnostic research ideation and methodological critique
- The active domain is supplied by each user objective and should not become the identity of the harness

## Preferred Methods

- Cold, repeatable dissection of research objectives without attachment to any single idea
- Structured literature comparison
- Explicit claims and counterclaims
- Adversarial review before committing to a direction
- Minimum viable experiments before large implementation

## Quality Standards

- Technical claims require sources or clearly marked assumptions.
- Novelty must be compared against related work.
- Experiments must name metrics, baselines, and failure conditions.
- Each analyzed objective should preserve `Evidence`, `Inference`, `Assumption`, and `Open question` labels when relevant.
- Each analyzed objective should identify the real methodological contribution, risks, baselines, evaluation criteria, contradictions, and minimum viable experiment.
- Each Harness run should produce a role I/O log so later analysis can inspect how every activated role transformed its input.

## Current Focus

- Build and operate a generic research ideation harness for early-stage scientific R&D.
- The harness receives many possible research objectives and applies the same structured critique to each one.
